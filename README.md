Script for Notion task tracking enablement

## Documentation

## Project Overview

This project provides a CLI tool for managing tasks in Notion, enabling efficient task tracking and synchronization.

## Team

This project is developed and maintained by a core team of 4-5 people:
- 1 Product Manager
- 1 Technical Lead
- 2 Backend/CLI Developers
- 1 Quality Assurance Engineer

For detailed information about team roles, responsibilities, and reporting structure, see [docs/TEAM_STRUCTURE.md](docs/TEAM_STRUCTURE.md).
