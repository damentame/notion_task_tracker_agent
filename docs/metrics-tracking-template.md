## Tracking Instructions

### Data Sources

1. **npm Downloads:**
   - Use npm stat API: https://api.npmjs.org/downloads/point/last-month/notion-task-tracker-cli
   - npm-stat.com for detailed analytics

2. **GitHub Metrics:**
   - GitHub Insights dashboard
   - GitHub API for programmatic access
   - Manual tracking in spreadsheet

3. **User Analytics (if telemetry implemented):**
   - Custom analytics dashboard
   - Usage tracking system
   - Privacy-respecting, opt-in only

4. **User Feedback:**
   - GitHub issues and discussions
   - Social media monitoring
   - Direct user surveys (quarterly)

### Update Frequency
- **Weekly:** Quick metrics check (downloads, stars, issues)
- **Monthly:** Full report using this template
- **Quarterly:** Strategic review with stakeholders

### Status Indicators
- 🟢 **On Track:** Meeting or exceeding targets
- 🟡 **Needs Attention:** Slightly below targets, addressable
- 🔴 **At Risk:** Significantly below targets, requires intervention

---

**Remember:** Metrics are a tool for learning and improvement, not just measurement. Focus on trends and insights, not just numbers.
